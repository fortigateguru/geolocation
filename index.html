איך מונעים השבתה ב-Safari (iOS)?

דפדפן Safari משבית טאבים לאחר כ-30 שניות ללא פעילות. המערכת שלנו מפעילה בלחיצת ההסכמה WakeLock API יחד עם WebAudio Silent Oscillator בתדר בלתי נשמע, כך שמערכת iOS מסווגת את הדף כנגן מדיה חי ונותנת לו תעדוף מעבד ורשת רציף.

איך מונעים השבתה ב-Android (Chrome)?

באנדרואיד, Chrome מפעיל מנגנון Doze/Throttling לאחר 5 דקות. שילוב של watchPosition(enableHighAccuracy) + Screen Wake Lock + מצב החשכת OLED שומר את מקלט ה-GPS פתוח ברציפות ללא כיבוי.
